Der Test ist falsch. Seine Annahme, dass nur die beiden manipulierten Felder kollidieren, ist falsch. Die Engine liefert `{0, 1, 28}` und liegt damit richtig.

- **Fall 3:** `faulty[1] = 5` kollidiert mit Index 0 in der Zeile. Spalte 1 enthält aber auch `solved[28] = 5` (Zeile 3, Spalte 1). Index 28 gehört also korrekt zur Konfliktmenge. Erwartet ist `{0, 1, 28}`.
- **Fall 4:** `faulty[9] = 5` hat den zweiten Konflikt in Spalte 0 mit Index 0. In Zeile 1 steht außerdem `solved[14] = 5`. Erwartet ist `{0, 9, 14}`.
- **Fall 5:** `faulty[10] = 5` kollidiert im Block mit Index 0, in Zeile 1 mit Index 14 und in Spalte 1 mit Index 28. Erwartet ist `{0, 10, 14, 28}`.

"""
Test‑suite für engine.py gemäß der Spezifikation.

- prüft generate, solutions, conflicts und CLUES
- führt `python engine.py neu <stufe>` aus und validiert die JSON‑Ausgabe

import json

from pathlib import Path

# Hilfsfunktionen

def abort(msg: str) -> None:
    """Gibt Fehlermeldung aus und beendet das Programm mit Code 1."""
    print(f"FEHLER: {msg}")
    sys.exit(1)


def ok(msg: str) -> None:
    """Gibt Bestätigung aus."""
    print(f"OK: {msg}")


def load_engine():
    """Importiert das zu testende Modul."""
    try:
        import engine
    except Exception as e:
        abort(f"engine.py lässt sich nicht importieren: {e}")
    return engine


def run_cli(level: str):
    """Startet `python engine.py neu <level>` und gibt das geladene JSON zurück."""
    cmd = [sys.executable, "engine.py", "neu", level]
    try:
        result = subprocess.run(
            cmd, capture_output=True, text=True, check=True, timeout=5
        )
    except subprocess.CalledProcessError as e:
        abort(f"CLI‑Aufruf fehlgeschlagen ({' '.join(cmd)}): {e.stderr.strip()}")
    except subprocess.TimeoutExpired:
        abort(f"CLI‑Aufruf timed out ({' '.join(cmd)})")
    try:
        data = json.loads(result.stdout)
    except json.JSONDecodeError as e:
        abort(f"CLI‑Ausgabe ist kein gültiges JSON: {e}")
    return data


def check_clues_count(puzzle: list[int], level: str, clues_dict: dict):
    """Prüft, ob die Anzahl der vorgegebenen Zahlen dem CLUES‑Wert entspricht."""
    expected = clues_dict.get(level)
    if expected is None:
        abort(f"Unbekannte Stufe '{level}' in CLUES")
    actual = sum(1 for v in puzzle if v != 0)
    if actual != expected:
        abort(
            f"Clues‑Zählung stimmt nicht für Stufe '{level}': erwartet {expected}, got {actual}"
        )


def check_unique_solution(engine_mod, puzzle):

    sols = engine_mod.solutions(puzzle, limit=2)
    if not isinstance(sols, list):

        abort(f"Puzzle hat {len(sols)} Lösungen, erwartet genau 1")

    sol = sols[0]

        abort("Ungültige Lösung zurückgegeben")

    # 1. Leeres Gitter → keine Konflikte
    empty = [0] * 81
